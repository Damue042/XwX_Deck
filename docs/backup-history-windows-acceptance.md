# Windows 备份与交互候选验收

验收日期：2026-10-27。版本：1.0.1。本轮只交付本地候选并同步源码，未发布安装包、更新资产或官网。

## 修改范围

- 设置页增加备份历史入口。列表只显示时间、备份名称和可执行操作。
- 新备份统一存入应用数据目录的 `backups` 文件夹。支持打开文件夹；可恢复记录需要确认，并在覆盖前备份当前内容。
- 恢复前校验原始文件和目标状态。外部修改、目录链接或活动中的恢复记录不会被静默覆盖。
- 兼容重复的 Desktop 旧恢复记录。只有旧记录摘要与新记录一致，且当前托管状态仍有效时，才归档旧记录。
- 普通按钮和设置入口保留颜色反馈，移除明显缩放与文字位移。备份、诊断面板使用短暂淡入。
- 同步页和模型页复用公共控件，保留大量列表处理、网格对齐和简洁操作。
- GitHub Pages 部署仅允许手动触发，源码推送仍运行构建检查。
