# 账号与服务切换

管理授权账号，并按需要启用账号轮换或跨服务切换。

## 添加账号

在“添加配置”中打开“订阅账号”。
选择界面支持的账号类型，按对应授权流程完成登录。
已经在本机登录的可识别账号，也可通过导入入口选择。

ChatGPT 官方登录与 API 授权分别管理。
两组账号各自保存顺序、选择与策略。
添加账号不会自动切换当前服务或模型。

导入本机账号保留来源登录文件。
来源客户端负责续期，Deck 引用对应身份。
取消授权或登录错误账号不会覆盖原有凭据。

## 查看用量

在账号面板查看服务返回的额度与重置时间。
未知额度不显示为零。
身份改变或失效后，旧读数会清除。

普通 API 没有额度来源时，不显示订阅额度。
服务商账单仍是扣款核对的依据。

## 账号轮换

在同一授权组内，按需要选择界面提供的策略。
新策略包括“用完再换”和“剩余额度最多”。
暂停的账号需手动恢复。
账号排序变化不会强行更换已有会话绑定的账号。

请求结果不明确时，不应重复发送同一任务。
已经输出内容或执行工具的请求，也不会盲目重放。

## 自动切换服务

在“我的配置”的增强功能中，开启服务切换。
Codex 与 Claude 分别保存服务顺序。
该功能默认关闭，关闭后仍会保留已配置的顺序。

只有可用账号确定耗尽后，才会按已开启的策略换服务。
普通限流、身份错误或网络错误不会触发跨服务重放。
模型选择沿用对应客户端的模型页设置。

更改服务后，应在同一段对话中验证续接。
操作方法见 [模型与客户端](models-and-clients.md)。

## 退出授权

在账号面板选择对应账号，再执行退出操作。
退出 API 授权后，对应服务选项会移除。
最后选择的模型仍会保留，失效授权可重新登录。

退出授权、移除客户端入口和卸载客户端是不同操作。
请按界面的具体对象确认范围。
