# macOS 安装

使用 DMG 安装或更新，并从“应用程序”启动。

## 安装

1. 在 [发布页](https://github.com/Damue042/XwX_Deck/releases/latest) 按芯片选择 Apple Silicon 或 Intel 安装包。
2. 打开 DMG，将 `XwX Deck.app` 拖入“应用程序”。
3. 从“应用程序”启动，完成首次设置。

在苹果菜单的“关于本机”中查看芯片。Apple M 系列选择 Apple Silicon，Intel 处理器选择 Intel。
正式分发包使用 Developer ID 签名和 Apple 公证。
具体制品的签名、装订与 Gatekeeper 结果见对应 Release 的验收记录。
镜像内仅提供应用与“应用程序”入口。

## 更新

在应用设置中检查更新，并下载新版本。
应用完成下载和校验后，可点击“打开安装包”。
等待旧应用安全退出，再拖入“应用程序”并选择替换。

如果仍有活动请求，先按提示等待或停止。
替换完成后，从“应用程序”打开新版。
确认新版正常运行，再推出安装映像。

首次使用步骤见 [快速开始](getting-started.md)。
