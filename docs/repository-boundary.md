# 仓库与隐私边界

XwX Deck 使用 `app.xwxdeck.desktop` 应用身份。
配置、凭据和必要缓存保存在 `xwx-deck` 目录。Windows 安装版的默认 Trace、日志和备份使用安装目录下的 `XwXTrace`，已有自定义目录保留。更新来自本仓库的 GitHub Releases。
新安装的服务列表为空，遥测推送默认关闭。
产品范围见 [产品定义](product.md)。

## 仓库检查

检查覆盖源码、文档、构建产物与完整 Git 历史。
历史范围包括所有本地引用可达的提交、标签、文件名和内容。
浅克隆会被拒绝，防止漏检已删除的文件。
远端分支、标签、PR 引用和平台缓存需单独核查。

检查拒绝私密标识、个人目录、凭据与无关背景信息。
编译时将本机目录映射为通用路径。
最终二进制还需检查 UTF-8 和 UTF-16 字符串。
检查通过后才能进入签名与发布。

这些规则只用于仓库与构建检查。
应用保留用户输入的服务名称、模型和地址。

## 配置验收

使用隔离配置目录和本地测试服务。
覆盖全新安装、已有配置与外部客户端配置。
导入只在确认后写入目标，保留来源文件与已有选择。
预览后来源或目标变化时，要求重新检查。
订阅刷新令牌不迁移，导入不自动激活连接。

连接检查不自动开启 Gateway、重启客户端或发送收费请求。
真实服务权限、额度、安装与更新继续分平台验收。
