## 实际客户端

Codex CLI 版本为 `0.163.0-alpha.10.2`。
它在同一线程完成 A→B→A。
停止 Trace 后，同一线程继续直连。
共完成四次实际客户端生成请求。

Harness 桌面版为 `0.2.1-rc.2`。
它在同一可见会话完成 A→B→A 三轮回答。
后两轮的实际请求保留了前面的回答。
另有一次独立标题请求，单独计数。
Trace 来源为 `deepseek-harness`，没有误标 Copilot。
停止 Trace 后，浏览器授权记录保留。
仅 Deck 的临时回环 Key 被移除。

实际验收发现，恢复临时 Key 后会留下 `refs: {}`。
旧适配器在下一次接管时拒绝这个合法空映射。
新适配器只展开空映射，保留其他字段与注释。
旧二进制复现失败，新候选的 HTTP 回归与实际客户端通过。
LF、CRLF、外部授权变化和再次接管均有单测。

两种实际客户端均使用合成账号和本地服务。
这不代表真实厂商、费用或官方订阅自然续期已验收。
实际安装枚举未逐项执行；检测和手动路径验证使用隔离夹具。

## 剩余边界

本轮没有验收真实 VS Code Copilot、Claude、Cline 等客户端界面。
它们的配置写入与请求适配采用隔离夹具回归。
Windows 的 CLI Home 生命周期检查按平台跳过。
系统凭据库的额外授权检查保留条件跳过。

当前 Windows 150% 缩放已实际渲染。
其他物理缩放、多显示器和 macOS 未验收。
其他窗口边界比例只由几何单测覆盖。
手工编写的非空内联 YAML 凭据映射仍拒绝自动改写。
该拒绝保留原文件，不替换未知字段。
真实断电、磁盘失效和恢复时权限突变未验收。

运行新版前，应从旧版托盘退出。
主窗口的 × 只收起到托盘。
安装目录被占用时会拒绝升级或卸载。
跨便携版与安装版共用数据目录时，并行启动由目录锁拦截。
