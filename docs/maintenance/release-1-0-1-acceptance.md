## 关闭行为

Mac 旧候选在 Trace 关闭时点击系统关闭按钮，会以状态码 0 结束进程。
此前只有 Windows 无条件隐藏主窗口，Mac 仍依赖 Trace 运行状态。
现在应用内关闭与原生关闭事件均直接隐藏主窗口，与 Trace 是否开启无关。
明确选择退出时仍执行原有退出与恢复流程，仪表盘关闭保持独立。

初轮补丁通过实际鼠标关闭及明确退出复核。
最终签名包另行完成 4 项原生关闭与恢复检查，覆盖 Trace 开、关两种状态及两条关闭路径。
恢复后完成 8 轮官方 Codex、Claude CLI 实际请求。
Windows 初轮候选已实际复核关闭按钮、Alt+F4 与托盘退出；最终制品结果分别记录。

### Windows 排查记录

独立认证测试最初把刷新后的令牌有效期设为 62 秒，与程序提前 60 秒刷新的规则仅差 2 秒。
繁忙 Runner 可能跨过该窗口，合法触发新一轮刷新，导致严格序号断言失败。
夹具改为在宿主停止时显式过期自有合成账号，保留真实时间过期检查和并发刷新断言。
另一次 ACL 查询超过 10 秒，未取得权限结果；等待上限改为 30 秒，权限断言保持严格。
这些夹具问题与产品的认证修复分别记录。

旧 Windows 私有权限使用 Owner Rights，目录可能由管理员组持有。
现从 TokenUser 读取当前用户 SID，将拥有者和唯一受保护的完全控制规则绑定到该用户。
严格检查拥有者、授权 SID、规则数量、完整权限和外部目录重定向拦截。
不修改凭据内容或外部客户端登录，不开放其他普通用户访问。
