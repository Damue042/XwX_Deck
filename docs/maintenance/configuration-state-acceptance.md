# 配置卡片状态验收

## 当前行为

客户端、API 服务和订阅服务使用同一套卡片状态样式。
确认未安装、未保存配置或未登录时，名称和图标略微淡化。
卡片仍可点击、选中和打开详情。
未知状态、检测失败和读取失败保持中性。

已保存的本地服务可以没有 Key。
普通 API、Coding Plan 和订阅账号分别判断。
自定义与导入入口保持正常颜色。
导入入口和任务标题统一使用“导入配置”。

## 原生账号状态

导入账号的元数据增加 `sourceLogin`。
该字段只描述绑定的来源登录，不携带凭据。

| 值 | 含义 | 卡片行为 |
| --- | --- | --- |
| `authenticated` | 来源授权当前有效 | 保持正常颜色 |
| `unauthenticated` | 已确认绑定账号移除、替换、未登录或授权失效 | 无其他有效账号时淡化 |
| `unknown` | 文件暂时不可读、格式变化或权限无法确认 | 保持中性 |

原生端只将有限、明确的失效原因归为未登录。
前端不匹配中文错误文案。
恢复原来源授权后，同一账号恢复正常颜色。
账号身份、来源文件和已选服务保持原状。

成功的订阅快照可以省略可选的 `supported` 字段。
前端将收到的快照视为有效结果。
只有 `supported: false` 表示当前不支持。
未收到快照与成功的空账号列表分别处理。

## 临时 CLI 授权租约

Unix 的 CLI 子进程继承临时授权目录的进程租约。
管理器退出后，存活的 CLI 继续保留该目录。
只有进程退出并释放租约后，应用才清理自己的目录。

首次完整回归和同一二进制复验均发现租约丢失。
原因是 `fcntl` 使用了固定第三参数的声明。
Apple ARM64 对可变参数使用不同的调用约定。
修复改为 POSIX 可变参数声明，并回读文件描述符标志。
父进程继续保留 `CLOEXEC`；仅在子进程执行前清除该标志。

新增 Rust 测试运行真实 `exec` 子进程。
它核对父进程标志、存活子进程租约和退出后的目录清理。
非法文件描述符必须阻止启动。
原有隔离进程回归继续覆盖强制退出、超时和重启恢复。
