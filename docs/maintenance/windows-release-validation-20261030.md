# Windows 更新验收

本轮日期为 2026-10-30。
源码基于提交 `8eba74d`。
测试使用隔离数据和本地服务。
本轮没有发布制品或替换正常安装。

## 当前结论

当前 Windows 候选尚未通过发布门禁。
下载校验与进程替换必须分别验收。
单元测试不能替代实际安装和更新。

首轮发现 worker 把进程创建成功当作启动成功。
修复后，主窗口在渲染并取得原生状态后发送就绪确认。
确认绑定本次随机标识、进程 ID 和可执行文件哈希。
worker 继续检查进程存活，再登记启动成功。
这不需要读取发布私钥或生成新的发布密钥。

新程序立即退出 23、确认后退出、错误标识和无确认均被拒绝。
失败保留新文件、旧备份和用户数据。
不会自动启动旧版本。
Setup 更新使用同一启动确认函数，并提前保留旧 EXE。
实际 Setup 安装仍需干净环境验收。
