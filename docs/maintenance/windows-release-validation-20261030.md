## 首次配置修复

正常模式首次选择服务时，CLI 配置目录可能尚不存在。
此前隔离模式预先创建目录，未覆盖该前提。
修复只初始化已有真实父目录下的最后一级。
已有目录及其权限保持原样。
若恢复记录已存在而目录消失，则拒绝重建。
用户最后选择与恢复记录继续保留。
仅保存本地偏好不会创建尚未使用的 CLI 目录。

回归实际使用正常配置模式。
它覆盖首次选择、偏好保存、重启和目录丢失保护。
Windows 的 Unix 继承租约部分仍跳过。
不将该跳过计为 Windows 进程树验收通过。
