应用身份、数据目录、已有选择和空服务列表规则保持原状。
新依赖和新的界面框架均未加入。

| 部分 | 当前行为 |
| --- | --- |
| Qwen Code | 一个实际 CLI 安装入口，无重复桌面入口 |

官网入口、安装说明和实际架构下载使用不同的文案。

它不是服务商 API Key。
复制操作不会将服务商 Key 带入剪贴板。

Qoder 的服务、模型和凭据字段以当前账号的官方向导为准。
应用不声明任意本地地址都能通过该向导。
已有受管文件和恢复账本按字段所有权恢复，外部修改保留。

## 统计与诊断

| 功能 | 核心检查 |
| --- | --- |
| 缓存命中率 | 整条请求配对累计，缺项请求单独排除 |
| 已知数量 | 保留可靠小计和已知的 0，未知字段显示“—” |
| 历史记录 | 只读补充覆盖信息，保留原始记录和冻结费用 |
| 会话续接 | 原始记录缺失时，保留旧摘要的可靠数量 |
| 最近失败 | 问题恢复和旧按钮刷新保留较新的失败 |
| 迟到响应 | 卸载后的失败不再写入全局记录 |
| 语言 | 记录原始提示，在显示时翻译消息和说明 |
| 叠层 | 全局层级使用样式变量，Toast 高于弹窗和菜单 |

Qwen 扩展计费明细经过完整校验后，省略的缓存写使用 0。
非法数值、矛盾总量和明确写入证据保持各自状态。
普通协议的字段要求保持原有规则。

共享语料覆盖 34 种用量形状。
原生单元覆盖零值、未知值、非法字段和历史续接。
Viewer 回归检查小计、模型差异、过滤和重复事件。
组件回归检查错误记录、重试、移除和双向语言切换。

这些检查使用隔离数据和本地上游。
实际账号、真实客户端重载和其他平台分别验收。
最终门禁与原生页面结果绑定整合源码和二进制哈希。
