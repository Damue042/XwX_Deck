# 工程维护要点

当前状态见 [整合验收](integration-acceptance.md)。
开发入口见 [开发说明](../development.md)。

## 配置与路由

保存不依赖模型目录健康。
服务、模型与账号保留最后一次明确选择。
客户端配置只修改有归属证据的字段。
外部变化保留并提示，不整文件覆盖。

## 请求与记录

请求、协议转换、工具续接与 Trace 分别核验。
失败、未知用量与真实计费分开记录。
Trace 新配置默认上限 1 GB，并开启超额自动清理。
已有容量和清理选择保持不变。

## 验收与发布

每项结果绑定源码、平台与制品哈希。
本地模拟服务、真实账号、安装和更新分别验收。
未执行的场景保留为待验，不沿用旧制品结果。
