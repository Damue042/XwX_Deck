# Gateway 生图修复验收

## 原因与修复

验证日期：2026-10-16。平台：macOS arm64。

本机 Codex 仍缓存旧 Gateway 端口。
旧实例已停止，但临时地址仍在客户端配置中。
临时诊断入口返回唯一的 503 标记。
内置生图返回相同标记，确认请求确实访问旧端口。
根据原实例的字段所有权账本，仅移除该临时地址。
模型、登录及其他配置保持原样。
现有会话的内存配置未强制重载。

代码同时修正官方订阅的 API 根地址。
官方模型接口默认使用 `/backend-api/codex`。
账号接口继续独立使用账号根地址。
显式 `openai_base_url` 保留。
统一历史 provider 保留自己的完整地址。
刷新路由时，先从活动 Gateway 的账本恢复来源。
不将受管临时地址再次当成原始上游。

普通转发失败补充脱敏诊断。
连接失败、上游 HTTP 错误和响应中断分别记录。
日志只保存来源域、端点哈希、阶段、耗时及错误类型。
不保存正文、完整路径、查询或凭据。
普通请求继续不进入 Trace，也不参与自动重试。
