# 公共运行时与引导整合

2026-10-27。本轮在当前主线基础上合并本地官网与新手引导增量，版本保持 1.0.1。

## 最终行为

- 未检测到任何已安装客户端时，推荐 ChatGPT、Claude。
- 没有待导入内容和待添加客户端时，跳过导入。
- 检测失败、来源错误和读取失败保留继续入口，不将未知结果当作空配置。
- 导览依次介绍接入 AI、选择模型、查看请求，共 3 步。
- 完成或明确跳过后回到模型页，不自动选择服务或开启 Trace。

官网补入已保存的首屏布局、整页点阵、真实界面自动演示和请求详情按需加载。
演示显式登记合成客户端，不改变正常应用的客户端管理规则。
共享 Viewer 通过可选参数加载静态示例详情，实时应用仍使用原有接口。
Trace 开启时切换服务不会保留已经满足的开启提示，其回归纳入后端检查。
模型目录加入批量能力索引与官方协议索引，并保持资料快照更新语义。
重复普通启动通过私有本地通道唤起已有窗口。静默自启不抢占焦点。
Trace 切换达到 3 秒才用 400 ms 淡入等待状态，提前完成取消计时。操作按钮在实际完成后恢复。
数据目录的 `startup-timings.json` 记录本地启动阶段耗时，不包含账号、凭据或请求内容。
API、订阅、我的配置和客户端详情共用底部操作栏。按钮高 32 px、间距 8 px、底边留白 16 px，右侧对齐内容边界。移除在左，取消和确认在右，正文独立滚动。
