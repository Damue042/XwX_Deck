## 后续优化建议

以下内容属于审查建议，未加入本轮候选。

1. 搜索明确区分当前请求和整会话。当前搜索只扫描已加载正文，尚未读取的历史可能漏检。整会话搜索应后台执行，并显示范围与进度。
2. 长详情中保留模式切换与查找入口。搜索命中后定位到具体段落并高亮，减少重新寻找的位置成本。
3. 同一窗口刷新后恢复侧栏宽度和折叠状态，继续尊重用户最后一次明确选择。
4. 空工具区和空事件区改为紧凑状态行。工具列表与 System 很长时先提供摘要，让消息与响应更早进入视野。
