# 用户手册

按使用任务查阅配置、模型、账号和请求追踪说明。

适用版本：XwX Deck 1.0.0。

## 页面

| 页面 | 用途 | 详细说明 |
| --- | --- | --- |
| 模型 | 为客户端选择服务与模型。 | [模型与客户端](models-and-clients.md)。 |
| 设置 | 管理连接、账号、外观与数据目录。 | [服务与配置](connections.md)、[设置与本地数据](settings-and-data.md)。 |
| Trace | 开启追踪，查看累计用量与接入状态。 | [Trace 与用量](trace-and-usage.md)。 |
| 仪表盘 | 查看会话、请求详情与实际路由。 | [阅读请求详情](trace-and-usage.md#阅读请求详情)。 |

首次使用请从 [快速开始](getting-started.md) 操作。

## 导入已有配置

在“添加配置”中选择“导入配置”。
核对检测结果，勾选需要的连接，再执行导入。
来源文件保持只读，导入不会激活服务。
支持的文件与冲突处理见 [导入已有配置](connections.md#导入已有配置)。

## 服务切换

先保存连接，再在模型页选择服务和模型。
目录刷新失败不会撤销已有选择。
切换后，应在同一段测试对话中核对实际路由。

普通服务切换见 [模型与客户端](models-and-clients.md)。
账号轮换和自动切换见 [账号与服务切换](accounts-and-switching.md)。

## Trace 数据

新配置默认上限为 1 GB，并开启自动清理。
已有的容量与清理选择继续保留。
详细记录与用量统计分别保留。

费用显示、容量和删除规则见 [Trace 与用量](trace-and-usage.md)。
记录可能包含业务正文，分享前应人工检查。

## 退出

关闭主窗口可能只会隐藏应用。
使用托盘、菜单栏或退出命令，进入安全退出流程。
应用先恢复受管连接，再停止 Gateway。

活动请求和外部配置冲突需要按提示处理。
处理步骤见 [无法安全退出](troubleshooting.md#无法安全退出)。

## 排障顺序

1. 检查服务、模型与客户端是否正确。
2. 检查“需 Trace”提示及接入状态。
3. 在请求详情核对上游与错误信息。
4. 按 [常见问题](troubleshooting.md) 处理对应情况。

## 更新

在设置中检查版本，按平台提示安装更新。
Windows 和 macOS 使用各自的更新流程。
macOS 由应用下载并校验 DMG，确认后打开安装包。
等待旧应用退出，再将新版拖入“应用程序”替换。
步骤见 [下载与安装](download.md)。

## 界面语言

打开“设置 → 应用 → 语言”，选择中文或英文。
首次启动按系统界面语言选择。
手动选择立即生效，并在重启后保留。
配置名、账号名与模型 ID 保持原值。

## 产品范围

XwX Deck 管理本机客户端的模型连接与请求追踪。
配置与 Trace 保存在本机，模型请求发送至所选服务。

XwX Deck 不提供配置同步、工具页或对话诊断。
详细说明见 [功能与范围](about.md)。
