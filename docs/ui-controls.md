# 公共控件

公共控件统一放在 `src/renderer/components/ui/`。页面组合控件并管理业务状态，尺寸、颜色、焦点和禁用态由公共组件及 `src/renderer/styles.css` 管理。复用现有 Base UI/COSS，不另建页面专用控件。

## 选用组件

| 用途 | 组件 | 约定 |
| --- | --- | --- |
| 主要操作 | `Button variant="default"` | 每个操作区突出主要动作 |
| 普通操作 | `Button` | 默认使用描边 |
| 次要操作 | `Button variant="ghost"` | 紧凑位置使用 `size="sm"` |
| 图标操作 | `Button size="icon"` | 提供可访问名称和 hover 提示 |
| 危险操作确认 | `Button variant="danger"` | 仅在明确的确认流程中使用 |
| 刷新 | `RefreshButton` | `busy` 绑定真实请求，期间阻止重复操作 |
| 并列操作 | `Group` | 用 `aria-label` 标识用途 |
| 列表搜索 | `SearchInput` | 必填 `label`，页面保留查询及过滤逻辑 |
| 单选分段 | `SegmentedControl` | 必填 `label`，已选项再次点击仍保持选中 |
| 多选开关组 | `ToggleGroup`、`ToggleGroupItem` | 使用 Base UI 的状态及键盘行为 |
| 可溢出导航 | `OverflowTabs` | 当前项始终可见，完整列表可搜索 |

状态计数通过 `SegmentedControl.options[].count` 传入，只在选中项展示。分段使用等宽网格，文字和计数作为整体水平、垂直居中。搜索不自动改变操作范围。列表为空、请求失败和执行进度由页面按实际业务反馈。

`OverflowTabs.action` 可提供列表级新增操作，包含 `label`、`onClick` 和可选 `id`。没有溢出时，操作与标签共用边框；发生溢出时，操作固定在“更多”菜单底部，不随搜索隐藏。组件同时预留操作宽度，单个长标签也可进入溢出布局。动作不作为列表选项计数。

页面与菜单搜索共用 `control-search` 样式。搜索框使用细边框，不使用阴影、内阴影或宽焦点光圈；键盘聚焦时通过边框变色标识位置。`ComboboxInput` 隐藏触发图标时自动采用该样式，保留 Base UI 的搜索和键盘行为。

图文按钮统一使用 16 px 图标。普通文字由 `Button` 包装，现有文字标签共用 `--control-label-optical-offset` 校正字体的视觉位置。当前字体的校正值为 1 px，纯图标保持几何居中；不在各页面单独调整图标或文字位置。

## 使用边界

- 默认点击反馈只改变底色、边框或颜色，不缩放或移动整个控件。配置行、设置入口与导航文字保持稳定；专门设计的主按钮动效按其组件规则处理。

- 页面样式只负责布局及明确的特殊需求，不复制整套按钮、搜索或选中态样式。
- 保留原有表单类型、禁用条件、事件、焦点归还及确认流程。删除配置继续使用 `ConfigurationDeleteAction`。
- 卡片选择、普通下拉选择和开关分别复用各自组件，不套用分段选择的交互。
- 不增加常驻说明小字。补充说明放在 hover 或用户主动展开的详情中。
- 说明和状态文案不使用间隔号作为分隔符，优先通过布局、空隙、括号或完整短句表达。
- 新增或修改公共组件时，同步共享核心并通过完整文件一致性检查。界面改动检查实际页面、键盘操作和窄窗口布局。
- 图文对齐按实际截图中的字形和图标检查，不能用元素框中心重合作为视觉居中的唯一依据。更换字体时重新核验中文、英文和数字组合。
