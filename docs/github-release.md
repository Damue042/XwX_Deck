# 构建候选与发布门禁

GitHub 用于维护公开源码和代码审查。
公开制品通过 Cloudflare 分发。
首个本产品本为 `1.0.0`。

## 候选来源

每个候选记录提交、源码指纹和制品 SHA-256。
Windows、Apple Silicon 与 Intel 使用同一份公共源码。
各平台结果分别登记。
旧包结果不改绑到新候选。

候选构建使用对应平台的原生工具链。
构建成功不等于安装和更新通过。
调试程序不进入正式下载目录。

## 更新分发

官网为 <https://xwxdeck.com/>。
稳定清单为 <https://xwxdeck.com/updates/stable/release.json>。
安装包放入既有 R2 存储桶。
下载地址使用 `download.xwxdeck.com`。
每个版本使用独立路径。
不覆盖已发布的同版本制品。

当前 Windows 源码仍使用旧默认更新地址。
仓库原有 Release workflow 仍包含 GitHub 草稿上传步骤。
两处都必须在正式发布前调整并验证。
不通过旧标签流程发布本轮候选。

## 验收要求

Windows 分别验收安装版和便携版。
覆盖下载、校验、替换、重启和数据保留。
坏包、断流、签名错误及启动失败均需实测。
夜间更新还需核对空闲状态和安全停机。

Mac 分别验收两种架构。
正式制品完成 Developer ID 签名、公证和票据装订。
客户端使用已批准的发布公钥校验更新。
私钥保持在既有安全存储中。

最终从生产域名下载同一候选。
核对版本、架构、签名、大小和哈希。
完成跨平台验收后再更新稳定清单。
当前进度见 [Windows 更新验收](maintenance/windows-release-validation-20261030.md)。
