# 托盘与长时间性能验收

2026-10-28 的 Windows 性能候选完成整小时测试，全部性能门禁通过。公开发布版本仍待确认，既有正式文件保留。

## 修复范围

Windows 托盘使用顶层窗口停用消息关闭。原生激活与 WebView 焦点移交完成后才接收失焦关闭，关闭入口同时更新 Tauri 可见状态，保证连续重开。主窗口根据实际前台窗口与 Windows 会话状态暂停后台点阵，恢复后继续；卸载时移除监听与动画帧。

旧 Trace 在后台逐条恢复。索引未变化时复用结果，新增原生捕获不重算全历史；旧会话补算单独排队。实时通知只传摘要。详情按需读取，列表保留摘要，正文只保留当前请求与一个对比基准。退出详情或删除会话时释放正文、DOM、延迟闭包和缓存。

超长、无换行的普通文本分段排版，首次约 24,000 字符，后续随滚动加载。边界查找限制在当前片段内，保留完整文本与 Unicode。Markdown、代码块、XML 和列表保留原有解析边界。

## 预先确定的通过标准

实际 Windows 原生包连续运行至少 1 小时。载入 20 个会话、约 745 MB 的旧历史副本。每次合成上游返回 1,120,000 字节文本，经过实际 Gateway 捕获。每轮切换页面、读取 4 个详情、切换日志与对比、返回总览并关闭查看器，每 5 轮隐藏与恢复主窗口。

每 5 秒采样主进程与全部 WebView2 子进程，包括 GPU、网络与渲染器。不主动触发垃圾回收或裁剪内存。

| 检查 | 标准 |
| --- | --- |
| 时长与操作 | 至少 3,600 秒、200 轮、800 次详情读取，无原生或渲染器错误。 |
| 峰值 | 整棵进程树私有内存低于 1 GiB。 |
| 空闲内存 | 末段相对预热后空闲中位数，进程树增长不超过 128 MiB，主进程增长不超过 64 MiB。 |
| 句柄与线程 | 进程树句柄增长不超过 500，主进程句柄增长不超过 150、线程增长不超过 32。 |
| 空闲 CPU | 末段平均不超过一个逻辑核的 5%。 |
| 资源 | 查看器关闭后释放订阅与窗口，无进行中的捕获，摘要缓存最多 8 个文件、8 MiB。 |
| 退出 | 15 秒后没有本轮进程树残留。 |

脚本在启动前校验源码指纹和 EXE 哈希。原始数据、操作计数、延迟及逐项门禁分别写入报告。短测明确不能通过时长门禁。

程序化原生窗口检查使用隔离配置和合成上游，不能代替真实账号、物理点击或 Mac 长测。当前系统输入保护返回 `GetCursorPos failed: Access is denied. (0x80070005)`，鼠标验收仍待完成。Mac 签名、公证及正式制品验收按 [发布流程](github-release.md) 单独执行。

## 长时间结果

脚本连续运行至少 3,600 秒，5 秒间隔的有效原生进程采样覆盖 3598.5 秒。完成 291 轮、1164 次详情读取、1164 次对比与 307 次实际本地请求。所有预先确定的门禁通过。

| 检查 | 结果 |

| 进程树采样峰值私有内存 | 861.7 MiB |
| 末段空闲私有内存 | 510.4 MiB |
| 相对预热后空闲增长 | -39.8 MiB |
| 主进程私有内存增长 | 20.0 MiB |
| 末段空闲 CPU | 0.56%（单逻辑核） |
| 进程树句柄增长 | -37 |

原有 20 个会话全部保留，20 个 JSONL 文件共 656,588,116 字节的哈希不变。没有通过删除历史、主动垃圾回收或内存裁剪取得通过结果。CPU 按单逻辑核的 100% 计算，不能直接当作任务管理器的整机占比。

最终 Windows 包的主界面 287 项、查看器 34 项、托盘 25 项、窗口生命周期 25 项、后端 104 组成功（含 1 项平台跳过），Setup 24 项通过。Setup 使用正常应用身份的合成旧版夹具与已解析的物理测试路径，首次身份错误与目录虚拟化失败保留。

[源码 CI](https://github.com/Damue01/XwX_Deck/actions/runs/40577890569) 的四项检查全部通过，绑定提交 `195e3c3`。该提交只补充 Mac 测试视口的实际尺寸校准；Windows 长测仍绑定上述冻结 EXE 与构建提交。Mac 的原生 WebKit 检查通过，不将其写成 Mac 整小时或签名制品验收通过。

本地请求耗时的 P95 为 261.3 毫秒；查看器完整脚本的 P95 为 6877.5 毫秒，后者包含打开窗口、4 次阅读、日志和对比切换，不是单条请求的加载时间。完整聚合结果见 [性能证据](evidence/performance-soak-20261028.json)。
