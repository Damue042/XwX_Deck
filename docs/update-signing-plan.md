## 清单签名

使用独立的 Ed25519 密钥对。
该密钥只签署更新清单，不用于模型服务或用户数据。

- 公钥和密钥标识写入 `assets/update-trust.json`。
- 私钥保存在本机 macOS 钥匙串。
- 建议服务名为 `XwXDeck.ReleaseSigning`。
- 建议账户名为 `release-ed25519-v1`。
- 私钥不进入 Git、网站、安装包或 Cloudflare。

签名脚本仅在用户手动发起发布时读取私钥。
不新增通用后台读取授权。
实际钥匙串访问规则在配置时另行确认。
备份应由用户保存到独立的加密介质。
脚本不自动选择备份位置，也不输出私钥。

密钥轮换需要分阶段执行。
先发布同时信任新旧公钥的客户端，再切换签名端。
更换 GitHub 账号不需要更换签名密钥。
