# 设置与本地数据

调整外观、存储位置和启动行为，按明确范围恢复或清理数据。

## 外观与语言

在设置中选择浅色、深色或跟随系统。
手动选择立即生效，并在重启后保留。
主窗口、仪表盘和请求阅读窗口使用同一外观选择。
Trace 外观选项用于调整追踪界面的显示效果。

打开“设置 → 应用 → 语言”，选择中文或英文。
配置名称、账号名称和模型 ID 不随语言切换而改变。

## 数据与日志目录

在设置的 Trace 分组中，查看或打开数据目录和运行日志目录。
点击对应的修改入口，选择新的目录。

修改 Trace 目录前，应用可能提示暂停转发。
正在处理的请求可能中断，请先核对活动任务。
更改完成后，应用尝试恢复原来的 Trace 开关。

原目录中的数据不会自动移动。
修改失败时，按提示检查目标目录并重试。
容量和清理规则见 [Trace 与用量](trace-and-usage.md)。

## 开机启动

在设置的应用分组中开启或关闭“开机启动”。
系统登录后是否自动启动，以该选择为准。
当前运行方式不支持时，界面会说明原因。

如果提示系统同步待完成，先保留当前选择，再按提示处理。
本地保存与系统实际生效是不同状态。

## 客户端增强选项

模型页按客户端提供对应的增强选项。
请先阅读选项说明，再决定是否开启。

“保留官方登录”用于切换模型服务时保留现有授权。
“管理会话历史”用于管理 ChatGPT 本地会话分类。
涉及正在使用的历史时，可能需要完全退出客户端。
关闭管理时，是否恢复原分类以确认框中的选择为准。

Claude 的 Desktop 选项用于应用模型连接。
它不提供规则、技能或文件同步。

自动服务切换的范围见 [账号与服务切换](accounts-and-switching.md)。

## 诊断与连接恢复

打开设置底部的“诊断与修复”。
当前问题与最近一次失败分别展示。
按对应提示检查记录，或恢复指定客户端的原有连接。

恢复只处理 XwX Deck 管理的字段。
外部修改会保留，冲突需要检查后再处理。
Trace 索引修复的范围见 [手动删除和修复](trace-and-usage.md#手动删除和修复)。

## 重置应用数据

重置会清理 Deck 设置、缓存、Trace 和运行日志。
自定义 Trace 与日志目录也在清理范围内。
需要保留的数据应在操作前另行保存。

在“诊断与修复”的“应用数据”行点击“重置”。
核对确认框中的范围，再决定是否继续。
Claude 与 ChatGPT／Codex 的核心配置默认保留。
只有额外勾选时，才会处理对应客户端配置。

涉及客户端核心配置时，可能需要关闭客户端。
请先保存正在进行的工作。
重置不是普通故障排查的首选步骤。
先按 [常见问题](troubleshooting.md) 定位具体问题。
