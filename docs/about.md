# 功能与范围

XwX Deck 管理本机 AI 客户端的模型连接，并追踪实际请求。

## 可以做什么

- 为已接入的 AI 客户端选择服务与模型。
- 管理自己配置的 API 连接和官方授权账号。
- 通过 Trace 查看请求、响应、Token、参考费用与耗时。
- 在本机适配部分请求协议，并处理支持的会话续接。
- 检查连接问题，按提示恢复受管配置。

新安装的服务列表为空。
添加自己的连接，或选择导入已有配置后，才能使用对应服务。
操作步骤见 [快速开始](getting-started.md)。

## 数据保存在哪里

设置、Trace 记录和运行日志保存在本机。
模型请求发送至当前选择的服务。
服务商如何处理请求内容，以其隐私政策为准。

Trace 记录可能包含对话和工具内容。
分享日志或截图前，请检查并移除敏感信息。
存储和清理规则见 [Trace 与用量](trace-and-usage.md)。

## 使用边界

XwX Deck 需要配合已有客户端使用。
它不提供聊天界面，也不提供云端会话同步。
配置、规则和技能不会在设备之间同步。

可用模型、套餐权限与实际账单由所选服务决定。
目录中显示模型，不代表账号一定有调用权限。
不同接口的支持范围见 [接口与兼容边界](provider-compatibility.md)。
