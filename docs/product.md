# XwX Deck Product

XwX Deck 是一个安静、精确、本地优先的 AI 客户端可观测工具。

## 核心用途

- 观察已接入 AI 客户端的真实模型请求、响应、Token、费用与耗时；
- 在官方服务、用户配置的 API 服务和用户授权的订阅账号之间管理模型路由；
- 在本地 Gateway 中处理协议适配、会话续接和上下文可移植性；
- 保持 Trace 数据、日志和客户端配置操作可见、可恢复。

## 产品边界

- 不是聊天客户端或云端会话同步服务；
- 不是通用抓包工具；
- 不提供客户端配置同步；
- 不提供工具页、ChatGPT 对话诊断或 Excel 转 Markdown；
- 更新来自本仓库的 GitHub Releases，元数据推送默认关闭。

## 设计原则

界面保持明亮、克制和可读。优先开放表面、清晰层级和可信状态，不使用装饰性 AI 渐变、拥挤卡片或不可解释的自动操作。
