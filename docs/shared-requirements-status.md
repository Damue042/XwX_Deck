# 共同要求与测试范围

核对日期：2026-10-14。
本文维护当前范围，不宣称全场景通过。
产品规则见 [交互约定](ux-product-requirements.md)。

## 当前共同要求

| 能力 | 当前要求 | 验收边界 |
| --- | --- | --- |
| 运行架构 | Rust/Tauri 与统一 React 前端 | 默认构建和运行边界通过 |
| 模型资料 | 服务有效声明优先，缺项来自 models.dev | 目录、真实生成和账单分别验 |
| 数值显示 | 已知零值、小额和未知值一致，无星号或未计价提示 | 当前 Trace 组件与 Viewer 各有断言 |
| 会话列表 | 单行、无 LIVE、会话优先留宽、分页连续 | 浏览器布局、原生窗口和物理操作分列 |
| 配置与反馈 | 草稿和最后选择保留，Toast 高于弹窗菜单 | 组件乱序与浏览器叠层分别验证 |
| 转发与记录 | 原请求和上游分开，工具完整，不盲目重放 | 合成协议检查不替代真实客户端续聊 |
| 数据容量 | 0 GB 只留用量，读取不改原始证据 | 原生存储与实际设置页分别验 |
| 侧边聊天 | 跟随实际线程与父子证据 | 淡色命名仍为设计，未声明实现 |
| 开发方法 | 模块编号、状态矩阵、入口归属和分层结果 | 新增断言要关联稳定编号 |

当前手册中旧的部分金额提示已清理。
模型菜单与保存失败的旧描述按最新要求统一。

## 仓库边界

工具页和配置同步不在产品范围。
保持独立数据根、更新源和 Git 历史。
当前没有旧发行版本兼容需求。
不增加其他产品的目录、凭据或更新源迁移。
正常重启和未来原生更新仍需保留本版数据。

## 本次文档核对

本次关联 13 个模块与 74 个稳定编号。
恢复通用的同线程续接和登录隔离编号。
已声明的默认、条件入口均归入功能目录。
专题脚本仍需另行选择，不由门禁次数代验。
更新命令或目录后，入口映射的过期检查会失败。

编译、类型、文档、运行边界和仓库边界通过。
实际 Trace 组件、局部开关和模型选择回归通过。
历史阅读使用 1,000 条合成请求。
Toast 在 780、1040 像素及日夜主题中可见且可点击。
浏览器使用本机已有 Playwright。
当前没有 Browser 插件，因此采用该验证路径。

上述页面检查属于 P。
未运行新的真实授权、收费生成或全量门禁。
原生包与真实客户端结果保持各自证据。
未安装、替换、发布应用或部署网站。
