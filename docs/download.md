# 下载与安装

选择对应系统的安装包，再准备需要使用的 AI 客户端。

## 获取 XwX Deck

下载入口统一位于 [官网](https://xwxdeck.com/#download)。
首个版本为 `1.0.0`，可下载状态以官网为准。
尚未提供对应链接时，请等待该平台发布。
静态手动下载和稳定自动更新分阶段开放。
提供安装包不表示自动更新渠道已启用。

正式发布后，官网通过 Cloudflare 分发以下三种制品。
GitHub 仅用于公开源码，不提供本次安装包下载。

| 系统与安装方式 | 下载后的文件名 | 下载状态 |
| --- | --- | --- |
| Windows x64 安装版 | `XwX-Deck-windows-x64-setup.exe` | 以官网为准。 |
| Windows x64 便携版 | `XwX-Deck-windows-x64.exe` | 以官网为准。 |
| macOS Apple Silicon | `XwX-Deck-mac-arm64.dmg` | 以官网为准。 |

本次不提供 Intel Mac 安装包。
文件由 `download.xwxdeck.com/releases/v1.0.0/` 分发。
静态下载地址在文件扩展名前包含完整 SHA-256，浏览器保存时使用上表名称。
下载菜单中的 `SHA-256` 链接提供同批总校验表。
每个静态对象另有同名加 `.sha256` 的单文件校验。
稳定更新所用的标准包名、`checksums.txt` 和签名清单留待后续发布。
隔离候选地址不作为正式下载入口。

以下安装步骤用于对应文件开放下载后。

## 在 macOS 安装

1. 确认 Mac 使用 Apple M 系列芯片，下载 Apple Silicon DMG。
2. 打开 DMG，将 `XwX Deck.app` 拖入“应用程序”。
3. 从“应用程序”启动 XwX Deck。
4. 完成首次引导，或跳过后在设置中添加连接。

更新时，先停止 Trace 并退出旧应用，再替换文件。
不要从安装映像中长期运行应用。
正式 Mac 包须完成 Developer ID 签名和 Apple 公证。

补充说明见 [macOS 安装](macos-first-run.md)。

## 在 Windows 安装

1. 下载 x64 对应的 Setup EXE。
2. 运行安装器，选择安装位置并完成当前用户安装。
3. 首次启动后，添加服务或导入已有配置。

需要便携版时，另行下载 `XwX-Deck-windows-x64.exe`，放在可写目录运行。

正式更新发布后，按应用提示下载并完成重启更新。
已下载更新且应用保持运行时，可在空闲时段自动安装。
自动安装要求在 02:00 至 05:00，且系统已空闲至少 15 分钟。
需确认的活动会话会阻止安装。
取消某个版本后，主动重新下载可恢复该版本的安装。

自动启动失败时，按提示手动打开更新后的程序。

## 更新 macOS 版

正式更新发布后，在应用设置中检查版本。
应用完成下载和校验后，按提示确认安装与重启。
如果仍有活动请求，先等待请求结束或按提示停止。

需要手动安装时，从官网获取对应版本的正式 DMG。
停止 Trace 并退出旧应用，再将新版拖入“应用程序”替换。
从“应用程序”启动新版，确认正常运行后推出安装映像。

## 准备客户端

已经安装客户端时，可以跳过本节。
尚未安装时，使用对应官方入口获取软件。

| 客户端 | 官方入口 |
| --- | --- |
| Codex | [Codex](https://openai.com/codex/)。 |
| Claude | [Claude 下载](https://claude.com/download)。 |

也可以打开“设置 → 添加配置 → 客户端管理”。
客户端下载与完成接入是不同步骤。
安装完成后，返回应用重新检测。

## 准备模型服务

API 连接需要服务商提供的地址与密钥。
按量 API 和订阅套餐可能使用不同的接口。
网页聊天账号的权益不等同于 API 调用额度。

在“API 服务”中选择预设，可打开对应的官方入口。
选择预设不会创建连接，仍需填写自己的密钥并保存。
不要在官网、截图或公开反馈中提交密钥。

安装完成后，继续阅读 [快速开始](getting-started.md)。
