# 下载与安装

选择对应系统的安装包，再准备需要使用的 AI 客户端。

## 获取 XwX Deck

从 [GitHub Releases](https://github.com/Damue042/XwX_Deck/releases/latest) 获取已发布安装包。
选择对应系统和架构的文件。

| 系统 | 安装包 |
| --- | --- |
| macOS，Apple Silicon | `XwX-Deck-mac-arm64.dmg`。 |
| macOS，Intel | `XwX-Deck-mac-x64.dmg`。 |
| Windows，x64 | `XwX-Deck-windows-x64-setup.exe`。 |

未列出的系统与架构，请先查看对应 Release 的说明。

## 在 macOS 安装

1. 按芯片选择 Apple Silicon 或 Intel 对应的 DMG。
2. 打开 DMG，将 `XwX Deck.app` 拖入“应用程序”。
3. 从“应用程序”启动 XwX Deck。
4. 完成首次引导，或跳过后在设置中添加连接。

更新时，先停止 Trace 并退出旧应用，再替换文件。
不要从安装映像中长期运行应用。

补充说明见 [macOS 安装](macos-first-run.md)。

## 在 Windows 安装

1. 下载 x64 对应的 Setup EXE。
2. 运行安装器，选择安装位置并完成当前用户安装。
3. 首次启动后，添加服务或导入已有配置。

需要便携版时，另行下载 `XwX-Deck-windows-x64.exe`，放在可写目录运行。

更新时，按应用提示下载并完成重启更新。
已下载更新且应用保持运行时，可在空闲时段自动安装。
自动安装要求在 02:00 至 05:00，且系统已空闲至少 15 分钟。
需确认的活动会话会阻止安装。
取消某个版本后，主动重新下载可恢复该版本的安装。

自动启动失败时，按提示手动打开更新后的程序。

## 更新 macOS 版

1. 在应用设置中检查更新，并下载新版本。
2. 下载完成后，点击“打开安装包”。
3. 确认并等待旧应用安全退出。
4. 将新版拖入“应用程序”，选择替换。
5. 从“应用程序”启动新版。

应用负责下载和校验安装包，最后的拖拽替换由用户完成。
如果没有通过应用下载，也可以从发布页获取 DMG，按相同步骤替换。

## 准备客户端

已经安装客户端时，可以跳过本节。
尚未安装时，使用对应官方入口获取软件。

| 客户端 | 官方入口 |
| --- | --- |
| Codex | [Codex](https://openai.com/codex/)。 |
| Claude | [Claude 下载](https://claude.com/download)。 |

也可以打开“设置 → 添加配置 → 客户端管理”。
客户端下载与完成接入是不同步骤。
安装完成后，返回应用重新检测。

## 准备模型服务

API 连接需要服务商提供的地址与密钥。
按量 API 和订阅套餐可能使用不同的接口。
网页聊天账号的权益不等同于 API 调用额度。

在“API 服务”中选择预设，可打开对应的官方入口。
选择预设不会创建连接，仍需填写自己的密钥并保存。
不要在官网、截图或公开反馈中提交密钥。

安装完成后，继续阅读 [快速开始](getting-started.md)。
