# 服务与配置

添加、编辑或导入模型连接，保留每个客户端的选择。

## 添加 API 服务

1. 在设置中点击“添加配置”。
2. 打开“API 服务”，选择服务预设或“自定义”。
3. 填写名称、URL 和 Key，保存配置。
4. 返回模型页，选择该服务及需要的模型。

名称用于区分连接，可以使用中文和空格。
同名连接各自保存，修改名称不会更换连接身份。
Key 默认隐藏，临时查看后会重新遮住。

预设只填写表单，不会创建默认连接。
API 按量服务与 Coding Plan 套餐分别配置。
套餐可能使用专属地址和密钥，请按服务商说明填写。

## 编辑和测试

点击设置中已保存的配置，进入“我的配置”。
选择左侧连接，在右侧修改名称、URL 和 Key。
切换页签时，未保存的输入会保留。
保存成功后，界面显示对应通知。

保存配置不依赖远端目录正常工作。
保存成功也不代表模型已经调用成功。
需要验证时，在配置的模型目录中发起单独测试。
先保存修改，再执行测试。

测试不更换客户端的默认服务和模型。
真实请求可能产生费用，请先核对服务商规则。

## 导入已有配置

1. 打开“添加配置”，选择“导入配置”。
2. 等待检测本机来源，或选择原配置文件。
3. 核对预览，勾选需要的项目。
4. 点击“导入”，再到模型页明确选择服务。

| 来源 | 可识别的原文件 |
| --- | --- |
| Magpie | `providers.json`。 |
| CC Switch | `cc-switch.db`，或旧格式 `config.json`。 |
| Claude CLI | `settings.json`。 |
| Codex CLI | `config.toml`；关联的 `auth.json` 保留在同一目录。 |

来源文件保持只读。
重复连接会跳过，同名的不同连接分别保留。
导入不会开启 Trace，也不会自动激活服务。

加密备份和 SQL 导出不等同于原配置文件。
无法识别时，请按文件说明选择原文件。
来源或目标在预览后发生变化时，须重新检测。

## 保护外部修改

其他工具可能同时修改客户端配置。
XwX Deck 会保留检测到的外部变化，并提示处理。
请先检查冲突，再重新应用需要的配置。

目录刷新失败不会撤销已保存的服务或模型。
新选择也不会被较早返回的目录结果覆盖。

## 删除连接

在配置编辑页点击“删除配置”，核对后确认。
正在使用的连接需要先停止 Trace，并切换客户端。
删除前应确认后续请求使用的目标服务。

账号授权的添加与退出见 [账号与服务切换](accounts-and-switching.md)。
